# Bilibili Downloader

> 一款基于 Python 的 B站视频下载工具，支持高清视频、批量下载、断点续传，无需安装 Python 环境即可运行（提供打包版）。

---

## 📖 简介

本项目是一款 **B站视频下载器**，拥有简洁的图形界面（GUI），支持 **BV号/链接解析**、**多清晰度选择**、**扫码登录**、**批量下载**、**暂停/恢复** 等实用功能。  
项目代码通过 **AI 辅助编程** 完成，但所有功能均经过充分测试，稳定可用。打包后的 `.exe` 文件可直接运行，无需 Python 环境。

---

## ✨ 主要功能

- 🎬 **视频解析**：输入 B站视频链接或 BV 号，一键解析出标题、封面、UP主、所有可用清晰度。
- 📥 **高清下载**：支持 360P ～ 1080P 及更高画质（**登录后**可获取大会员专属清晰度）。
- 🔐 **扫码登录**：内置 B站扫码登录，轻松获取 Cookie，突破低清限制。
- ⏯️ **下载控制**：支持 **暂停/恢复**、**取消下载**，下载进度、速度、剩余时间实时显示。
- 📦 **批量导入**：支持从 `.txt` 文件批量导入链接，自动排队下载。
- 🗂️ **自定义目录**：可自由选择下载文件的保存位置。
- 📋 **下载历史**：自动记录已下载视频的信息，方便回顾。
- 🧩 **音视频合并**：自动调用 FFmpeg 合并音视频（高清视频音画分离），输出完整 MP4。
- 📖 **内置帮助**：首次运行自动弹出使用说明，菜单栏可随时查看帮助和关于信息。

## 🚀 快速开始

### 方式一：使用打包版（推荐普通用户）

1. 从 [Releases](https://github.com/你的用户名/BilibiliDownloader/releases) 下载最新版本的 `BiliDownloader.exe`。
2. **将 `ffmpeg.exe` 放入与 `BiliDownloader.exe` 相同的文件夹**（否则高清视频无法合并音视频）。
   - 如果你没有 `ffmpeg.exe`，可以从 [FFmpeg 官网](https://ffmpeg.org/download.html) 下载或向作者索取。
3. 双击 `BiliDownloader.exe` 即可运行。

> ⚠️ 部分杀毒软件可能会误报，请添加信任或暂时关闭。

### 方式二：源码运行（开发者/技术用户）

1. **克隆仓库**：
   ```bash
   git clone https://github.com/你的用户名/BilibiliDownloader.git
   cd BilibiliDownloader
   ```

2. **创建并激活虚拟环境**（推荐）：
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS/Linux:
   source venv/bin/activate
   ```

3. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```

4. **安装 FFmpeg**（可选，但推荐）：
   - 将 `ffmpeg.exe` 放在项目根目录，或安装到系统并配置环境变量。

5. **运行程序**：
   ```bash
   python main.py
   ```

## 📖 使用说明

### 1️⃣ 首次运行
- 程序会自动弹出 **使用说明** 窗口，详细介绍各项功能。
- 可在菜单栏 **帮助 → 使用说明** 随时查看。

### 2️⃣ 登录账号（推荐）
- 点击 **“登录B站”** 按钮，程序会生成一个二维码。
- 使用 B站手机 App 扫描二维码，即可完成登录。
- 登录后，可获取更高清晰度（如 1080P、4K 等，取决于账号权限）。

### 3️⃣ 下载视频
- 在输入框中粘贴 B站视频链接（例如 `https://www.bilibili.com/video/BV1xx...`）或 BV 号。
- 点击 **“解析”** 按钮，程序会获取视频信息并显示可用清晰度。
- 在下拉菜单中选择想要的清晰度。
- 点击 **“下载”** 即可开始下载。

### 4️⃣ 批量下载
- 准备一个 `.txt` 文件，每行一个 B站视频链接或 BV 号。
- 点击 **“批量导入”**，选择该文件，程序会自动依次下载。

### 5️⃣ 下载控制
- **暂停/恢复**：下载过程中可随时暂停，再次点击“恢复”可继续（支持断点续传）。
- **取消下载**：取消当前任务并清理临时文件。

## ❓ 常见问题

### Q1: 为什么只能看到 360P/480P？
**A**: 请先登录 B站账号。登录后，程序会获取你的账号权限，显示更高清晰度（如 1080P、4K 等）。

### Q2: 下载的视频没有声音？
**A**: B站高清视频音视频是分离的。请确保 `ffmpeg.exe` 已放在程序同目录下，或已正确安装并配置环境变量。

### Q3: 打包版报“未找到 FFmpeg”怎么办？
**A**: 请将 `ffmpeg.exe` 复制到 `BiliDownloader.exe` 所在的文件夹，重新运行程序。

### Q4: 程序无法运行或被杀毒软件拦截？
**A**: 部分杀毒软件可能会误报 PyInstaller 打包的程序，请将程序添加至信任列表，或暂时关闭杀软。

### Q5: 能否在 macOS/Linux 上运行？
**A**: 源码版支持（需安装 Python 依赖），但打包版仅提供 Windows 可执行文件。
